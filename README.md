# Folketrygdle 2026

Minimalistisk daglig finansquiz basert på Folketrygdfondets offisielle aksjeportefølje for 2026 (Statens pensjonsfond Norge og Statens fond i Tromsø, 334 selskaper pr. 30. juni 2026).

## Slik fungerer spillet

Gjett det hemmelige porteføljeselskapet på opptil 6 forsøk. For hvert forsøk vises tilbakemelding på fem nøkkeldimensjoner:

- **Land**: Norge, Sverige, Danmark, Finland eller Island (samt himmelretning mot målet).
- **ICB-Sektor**: Offisiell bransjeklassifisering i Folketrygdfondet (grønn for eksakt bransje, gul for beslektet bransje).
- **Børsverdi**: Selskapets totale markedsverdi i mrd. NOK (`↑` indikerer at målet er større, `↓` at målet er mindre).
- **FTF-Post**: Folketrygdfondets aksjebeholdning i selskapet og rangering (`#1` til `#334`).
- **Eierandel**: Folketrygdfondets eierandel i prosent og fondsmandat (`SPN` / `SFT`).
